# Changelog

## Unreleased

- One-time offer, per machine, to run `xcode-select --install` when the macOS SDK cannot be found; also available as **C++ Modules: Install Command Line Tools**.

## 0.1.0

- First release: mcppls language server with clangd 23.1 and the mcppls-kit standard library kit built in.
- One language status item, four commands, four optional settings.
- Module-name navigation and import completion; diagnostics for unresolved modules.
- One-time offer to turn off the language features of other C++ extensions in the workspace.
